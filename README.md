# broCode v6

Windows 10/11 x64 installer distribution.

Download **BrocodeSetup-6.0.0.exe** from [Releases](https://github.com/SHIVANSH-BHARTI2002/broCode/releases/latest).

Setup installs for the current user, creates shortcuts, and installs WebView2 if missing (internet required). Supply your own API key or sign in after installation.

Silent installation: `BrocodeSetup-6.0.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART`.

The installer is unsigned. Clean-PC installation and full application runtime have not been tested.
